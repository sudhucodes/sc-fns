## Community & Support

We are building `sc-fns` to be the cleanest, fastest, and most reliable TypeScript utility toolkit available.

---

## Reporting Issues & Bugs

If you encounter unexpected behavior or bugs with any function, please file an issue on GitHub with reproduction steps:

- [GitHub Issues Tracker](https://github.com/sudhucodes/sc-fns/issues)

When filing an issue, please include:

1. The function name and arguments used.
2. The expected output vs the actual output.
3. Your runtime environment (Node.js version, browser, Next.js, Vite, etc.).

---

## Contributing

Contributions are warmly welcomed!

1. Fork the repository on GitHub.
2. Clone your fork and install dependencies using `pnpm install`.
3. Add or update functions in `packages/sc-fns/src/`.
4. Ensure all tests and type checks pass with `pnpm run typecheck && pnpm run lint && pnpm run build`.
5. Submit a pull request.
